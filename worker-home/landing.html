How we ship

The privacy promise is checkable.

"Private by design" is easy to say. Here is the machinery that makes it verifiable — on every release, not just the marketing page.

01

Private by architecture, not policy

PDF Studio and the toolbox run entirely in your browser; the CLIs have zero runtime dependencies and make no network calls. There is no server to trust — because there is no server.

02

Audited releases

OpenSSF Scorecard 7.7, npm packages with SLSA provenance, cosign signatures, SHA-pinned CI actions, Dependabot, secret-scanning push protection.

03

Proofs, not screenshots

17 committed design artifacts regenerate byte-identically in CI. The proof set includes six real public-domain government pages — NPS, NASA, NOAA, Census, Federal Register, Smithsonian.

04

One protected main

Every change lands by PR through 16+ required checks — 160 tests, a reproduction guard, docs-parity gates, a workflow linter. 46 merged PRs and counting.
